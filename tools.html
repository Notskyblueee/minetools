📋 How to Use Slot Numbers
This visual guide shows the exact slot numbers for a double chest (large chest) in Minecraft. Each slot is numbered from 0 to 53.
Rows 1-3 (Slots 0-26): Upper chest half
Rows 4-6 (Slots 27-53): Lower chest half
